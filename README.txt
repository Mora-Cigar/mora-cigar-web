MORA CIGAR — SITIO WEB

Contenido listo para GitHub Pages.

Estructura:
- index.html
- styles.css
- script.js
- assets/ (6 imágenes proporcionadas)

Para publicar en el repositorio mora-cigar-web:
1. Sube TODOS los archivos y la carpeta assets.
2. Verifica que index.html quede en la raíz del repositorio.
3. En GitHub: Settings > Pages.
4. Selecciona Deploy from a branch, rama main y carpeta / (root).
5. Guarda y espera la publicación.

Importante: las imágenes usan rutas relativas, por ejemplo assets/logo-cigar.jpg, para evitar errores de rutas en GitHub Pages.
